# 联采报价单据
一个 lot 为一个声明的交易时段。报价中的 packages 每项说明必须一起买下的时段和电量。任何拆单都要由报价人事先列为独立 package。标有同一个 exclusion 的一组报价最多选一项。报价再送一次时版本号递增，receipt_at 为收到时间而非供应商填写时间，withdrawn 表示该报价整项撤回。截止时刻及其后收到的报文不能进入本轮，开标以公告中的 open_at 为准。
`lots` 记录按时段的可接受最大电量、最低履约量与优先级。公告允许部分中选时，未达到最低履约量的 lot 不成交。满足硬约束后，依次比较最高优先 lot 的进展、副优先 lot 的进展、可成交总量、总支出和按报价编号排序的字典序。优先级数字小的排前；各 lot 的进展用该 lot 成交量。预算字段 `limits` 包括分组上限和整轮上限，允许不同组搭用的总预算仍须在独立上限内。其他组不能仅因共享同个采购编号被复核冻结；若异议中的报价事实涉及全轮预算，就要判断它是否真实改变其他组可签结果。
异议资料是对资格事实的主张，orig 表示被质疑的资格凭证，不是自动作废指令。最终授标有效期取采购发出的截止和报价 expires_at 中较早者。已依法签署的分包为后续候补约束。
## 资料发布
报文样例位于 `data/`，每个集合是一个 UTF-8 JSON 数组，id 是集合内的来源标识。跨集合引用使用原标识。没有值的可选项可以不提供，JSON null 表示已报告但暂未确认的值。
